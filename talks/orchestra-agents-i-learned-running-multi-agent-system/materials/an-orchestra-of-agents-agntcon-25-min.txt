The fix is ten tokens
Verified with a query about a tool announced 2 days earlier: all 5 repos dated inside those 2 days.
def inject_current_date(callback_context, llm_request):
    today = datetime.now(timezone.utc).strftime("%Y-%m-%d")
    llm_request.append_instructions([
        f"Today is {today} (UTC). When surfacing third-party "
        f"content, prefer the most recent items unless the user "
        f"asks for historical material."
    ])  # <-- system_instruction, not a get_date TOOL (that costs a round trip)

A websocket bot on serverless (yes, really)
--min-instances=1 : scale-to-zero hangs up the Discord
websocket
--max-instances=1 : in-memory sessions... two instances =
split-brain memory
--no-cpu-throttling : Cloud Run throttles CPU between
requests. A websocket bot's work happens between requests.
PYTHONUNBUFFERED=1 : or the stdout telemetry pipeline just...
buffers

--- slide 36 ---
@codewith_ahsan
The epilogue 💸
Same Dockerfile, same image. The flags that keep a websocket bot alive on Cloud Run are the flags that make
it expensive there.
Always-on + unthrottled CPU = instance-based billing
1 vCPU rented 24/7 ≈  $47 / month. The free tier covers ~50 hours
of it.
Today the same container runs on an Always-Free e2-micro VM:
~$3-4 / month

--- slide 44 ---
@codewith_ahsan
37 minutes. The fix: drain everything,
keep the last word.
Report 19:55 →  root cause 20:01 →  deployed 20:32. Leaves speak first, orchestrators speak last.
async for event in runner.run_async(...):
    events_seen.append(event)
    if event.is_final_response() and event.content and event.content.parts:
        text = event.content.parts[0].text or ""
        if text:
            response_text = text  # keep latest; synthesizer wins
# no break. The stream ends when the stream ends.
