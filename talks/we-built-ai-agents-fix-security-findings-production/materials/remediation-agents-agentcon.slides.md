## Slide 16 — Nobody has to ask for any of this
**Text.** ON THE PR · SELF-HEAL / Nobody has to ask for any of this / EVENTS IT REACTS TO / CI goes red — Reads the failing job log, repairs the cause, re-verifies, pushes. / The base branch moves — Merges the new base into its own branch, re-verifies, pushes. / CI goes green — Green is not proof. If the repository's checks only scan secrets or metadata, the agent builds the change itself, or says in its reply that it did not. / WHAT IT CANNOT DO / Keeping a branch current is exactly when an agent would reach for rebase or force-push. / It cannot. A PreToolUse hook blocks the call before it runs. It is not an instruction a prompt can override. / force-push (struck through) · cherry-pick (struck through) · amend (struck through) / The same hook blocks gh pr merge and gh pr close, so the agent cannot merge or close its own pull request. That is enforced in code, not left to good behaviour. / Opening a pull request and walking away is what makes an agent untrustworthy. / 16 / 20
**Shows.** Two columns: left lists three self-healing trigger events with what the agent does for each; right explains a hard technical constraint, with a small table showing three git commands (force-push, cherry-pick, amend) all struck through to show they are blocked, illustrating that the restriction is enforced by a pre-tool-use hook rather than by prompted instruction.
