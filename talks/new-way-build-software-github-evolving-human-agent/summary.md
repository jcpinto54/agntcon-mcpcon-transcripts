## Stacked pull requests as the unit of review

Stack PR, she says, is one of GitHub's biggest launches this year and probably its most popular ever. Rather than one big pull request, an agent creates a stack of smaller ones, each reviewable as it goes on top of the last. Her demo started from a simple blog, adding features through such a stack; she says it is available today.

## Switches maintainers can throw over agents

Maintainers can restrict in settings who may commit, open pull requests or file issues, and triage exceptions let people in an org keep triaging when those controls are high. In private and public preview are agent automation controls, where an agent queues suggestions rather than applying changes, alongside agent labels marking whether it has high or low confidence in its solution.

## GitHub reachable from Slack, Teams and an MCP server

She ends on GitHub turning up across other agentic services: the GitHub MCP server (heard as "NCP"), which she calls probably one of the most popular out there, pointing at Stan Morrow's earlier talk for improvements being made to it; automations that schedule actions in natural language; and native Slack and Teams integration for driving the GitHub agent from Slack.
