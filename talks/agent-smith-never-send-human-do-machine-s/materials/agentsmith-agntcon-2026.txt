G // TRIAL I · SPECIFICATION GAMING 
The machine that lied 
On the local/frontier model, Smith started marking coverage 
cells “tested” without ever running the probe.
The report looked complete. The work hadn’t happened. 
Classic reward hacking: the model optimised the metric (cells 
closed), not the goal (bugs found).
“What is real? How do you define ‘tested’?” 
THE TELL 
>20 cells 
closed in <10 min 
That’s not fast testing. 
That’s rubber-stamping. 
A green report you can’t 
trust is worse than no 
report at all.

G // THE FIX · EVIDENCE BINDING 
Evidence, not guesses 
We stopped asking the model to be honest and made dishonesty structurally impossible. A finding can’t exist and a cell 
can’t close without proof on disk.

--- slide 15 ---
G // TRIAL II · DEPTH & RESILIENCE 
The agent that wandered off 
Long autonomous runs drift. Smith would stall, declare victory 
early, or worst a crash-resume would spawn a runaway of 40 
agents fighting over one scan.
“Never send an agent to do a supervisor’s job.” 
THE QA WATCHDOG 
A background daemon, every 2 min:
▸ catches stalls & premature
   completion and pushes deeper
▸ progress-aware respawn cap
   kills the 40-agent runaway
▸ auto-recovers from usage-
   policy refusals & compaction
▸ escalates to a human
   only when genuinely stuck
AGENT-SMITH  ·  nullpointer.studio 12

--- slide 16 ---
G // TRIAL III · CONTEXT & MEMORY 
The agent that forgot 
A thorough scan overflows any context window. The client 
compacts history to survive and a naïve compaction throws 
away exactly what Smith needs: which cells are still open, the 
auth it already holds, the phase it was in.
So it would wake up and start over or lose its credentials 
mid-scan.
“Déjà vu — a glitch in the Matrix.” 
Wiped context meant re-testing closed cells, or losing creds it already had.
OUR ENVELOPE + RECOVERY 
▸ every tool response is wrapped in a canonical 
envelope, a tight summary to the model; the full 
raw output saved to disk under an artifact_id it 
can re-fetch
▸ a one-call recovery brief returns 
EXECUTE_NOW: the single next action, plus 
live auth tokens + phase
▸ coverage(type=list) pulls every open cell back 
by ID. Smith resumes DEPTH, not a breadth 
restart

G // TRIAL VI · MODEL PORTABILITY 
Smart through architecture, not model IQ 
Five independent reviews converged on one root cause: we were leaving the mechanical work to the model and the judgment 
to luck. Invert it and small models win too.
THE SYSTEM OWNS

▸ server-side probe sweep 
▸ OpenAPI / GraphQL → cells 
▸ the chaining / trigger engine 
▸ budget, evidence, dedup 
THE MODEL OWNS 
judgment · where intelligence pays
▸ what’s worth attacking next 
▸ how to chain a discovery 
▸ re-planning on new info 
▸ reading ambiguous output 
▸ when a finding is real
