ON THE PR · SELF-HEAL
Nobody has to ask for any of this
EVENTS IT REACTS TO
CI goes red
Reads the failing job log, repairs the cause, re-verifies, pushes.
The base branch moves
Merges the new base into its own branch, re-verifies, pushes.
CI goes green
Green is not proof. If the repository’s checks only scan secrets
or metadata, the agent builds the change itself, or says in its
reply that it did not.
WHAT IT CANNOT DO
Keeping a branch current is exactly when an
agent would reach for rebase or force-push.
It cannot. A PreToolUse hook blocks the call before
it runs. It is not an instruction a prompt can override.

amend
